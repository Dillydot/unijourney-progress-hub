# UniJourney Progress Hub

Student dashboard for tracking study progress: credits, grades, study plan, calendar, news and notifications. Bilingual (English / Swedish).

Currently a front-end prototype with example data (a KTH TTBEM master's student).

## Stack

TanStack Start (React 19, SSR via Nitro), Vite, TypeScript, Tailwind CSS v4, shadcn/ui, Recharts.

## Development

```sh
bun install
bun run dev
```

`bun run build` builds to `.output/`; `node .output/server/index.mjs` serves it.
